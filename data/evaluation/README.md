# Jeu de référence Puls-Events

25 cas rédigés à partir du snapshot OpenAgenda fourni et actualisé au 14 septembre 2026.
Aucune réponse de Mistral n’est utilisée comme vérité terrain. Les références
reprennent les champs du CSV (UID, titre, lieu, dates et URL), conservés dans chaque cas.
Ces annotations sont proposées par l’assistant et restent à relire par une personne :
`human_reviewed` vaut `false`. Ne pas présenter ce jeu comme déjà validé humainement.

Les questions ciblées permettent de vérifier des UID précis. Pour les questions
ouvertes, les listes de pertinence peuvent être incomplètes : ne pas généraliser
les scores à toutes les recommandations culturelles. Les cas d’absence et
ambiguïté se mesurent séparément, sans rappel artificiel égal à 1.
